## Hi, I'm Javohir 👋

**Full-stack developer building useful web products with React, TypeScript, and Firebase.** Based in Jizzakh, Uzbekistan, I enjoy turning real-world needs into clear, reliable user experiences—from e-commerce and business workflows to real-time applications.

I care about writing maintainable code, building intuitive interfaces, and understanding how the product works end to end. I also explore native iOS development with SwiftUI.

### What I bring

- **Frontend development:** React, TypeScript, JavaScript, responsive UI, Tailwind CSS
- **Application services:** Firebase Authentication, Cloud Firestore, and real-time data workflows
- **Product thinking:** E-commerce, inventory, order management, role-based experiences, and multilingual interfaces
- **Additional experience:** Node.js, Telegram bots, SwiftUI, Git, and Vercel
